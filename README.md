# 🎓 SoftUni – HTML & CSS

My solutions to the exercises and exams from the **"HTML & CSS"** course at [SoftUni](https://softuni.org).

## 📖 About the course

The goal of the "HTML & CSS" course is to lay the foundations of web technologies, and more specifically to introduce HTML5 and CSS3. It covers the basics of web development, web browsers, and tools for HTML/CSS/DOM development, and builds practical skills in using the language for describing web content (HTML) and the language for styling web content (CSS).

The course covers the main HTML tags, paragraphs, lists, tables, forms, controls, and semantic HTML tags. It focuses on the core CSS selectors and styles, working with classes, presentational rules, and positioning and layout rules in CSS. It also covers the latest features of the HTML5 and CSS3 standards.

The course emphasizes hands-on practice with HTML and CSS: participants work on real projects, building web pages, implementing fragments of existing sites, and creating complete modern websites with good visual design, a modern structure, and mobile support.
